# Stack DSA Problems in Java

This folder contains my practice problems on **Stacks** using Java.

## Concepts Covered

- Stack implementation using arrays
- Push and Pop operations
- Peek / Top operation
- Checking whether a stack is empty
- Evaluating postfix expressions
- Infix to Postfix conversion
- Infix to Prefix conversion
- Finding the minimum element in a stack
- Next Greater Element

## Language Used

- Java

## Objective

To understand stack operations, learn how stacks work using the LIFO (Last In, First Out) principle, and improve problem-solving skills for coding interviews and placements.

## Practice

I regularly solve stack problems and upload my solutions to improve my understanding of Data Structures and Algorithms.
